## Basic socket programming and file handling
`server.c` and `client.c` in the root directory gives a basic example of file handling(read, write) through client. It assumes a sample file that is already present in the server. 

## Advanced socker programming and file handling. 
In the full feature directory, we have server client code that can handle uploading a file from a client, inviting other client to edit and collaborate in a same file. **Collaboration** include reading and writing in files upoaded by clients.
